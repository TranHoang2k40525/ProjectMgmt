1.1 Ma Trận Quy Tắc Đặt Tên (Naming Rules)

Đối TượngQuy Tắc Đặt TênVí Dụ Cụ Thể
URL Endpoint kebab-case danh từ số nhiều (plural) /api/v1/work-items, /api/v1/workflow-transitions
Query Parameter camelCase pageSize=20&isRead=false&searchQuery=CRM
JSON Body Request/Response camelCase đồng nhất 100% 3 module issueKey, storyPoints, createdById, acceptanceCriteria
Database Mapping snake_case (MySQL) / PascalCase (.NET EF Core) issue_key -> issueKey, user_id -> userId
Datetime ISO 8601 UTC string format 2026-09-22T19:54:00.000Z
UUID / GUID UUID v4 string (36 ký tự lowercase) 01a09072-8caa-7743-8a5f-be64f3d5c3b8
