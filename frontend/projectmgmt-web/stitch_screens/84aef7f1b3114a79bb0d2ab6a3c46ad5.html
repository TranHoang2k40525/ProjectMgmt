[DEVOPS] Dựng Docker Compose local MySQL 8.4 + Ollama LLM Service

description Mô tả kỹ thuật (Description)

Mục tiêu phát triển:

Thiết lập môi trường phát triển cục bộ chuẩn hóa bằng Docker Compose bao gồm cơ sở dữ liệu MySQL 8.4 Enterprise LTS và service Ollama phục vụ chạy suy luận trực tiếp mô hình ngôn ngữ lớn cục bộ (Llama 3 8B & Qwen2.5-Coder) phục vụ kiểm thử Đồ án Tốt nghiệp K65 - Khoa CNTT HUCE.

Yêu cầu kiến trúc & cấu hình container:
  • Port mapping MySQL: Khai báo mở cổng 3306:3306; cấu hình named volume kiên cố huce_mysql_data ngăn thất thoát dữ liệu.
  • Service Ollama Engine: Khai báo mở cổng 11434:11434, kích hoạt tham số deploy.resources.reservations.devices hỗ trợ GPU passthrough (NVIDIA CUDA).
  • Cơ chế Healthcheck: Chu kỳ kiểm tra định kỳ 10s cho cả hai dịch vụ, thời gian phản hồi chờ 5s, tối đa 3 lần thử trước khi đánh dấu unhealthy.
  • Bảo mật & Quản trị biến môi trường: Cung cấp tệp mẫu .env.example với mật khẩu mặc định được mã hóa an toàn, không commit thông tin nhạy cảm.
